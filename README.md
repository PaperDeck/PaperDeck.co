# PaperDeck.co

Official download page for [PaperDeck](https://github.com/PaperDeck/PaperDeck).

## Development

Clone the repository:

```sh
git clone https://github.com/PaperDeck/PaperDeck.co.git
cd PaperDeck.co
```

Install dependencies:

```sh
pnpm install
```

Start development server:

```sh
pnpm dev
```

## Build

Create production build:

```sh
pnpm build
```

## Tech Stack

- Astro
- React
- Tailwind CSS
- TypeScript
